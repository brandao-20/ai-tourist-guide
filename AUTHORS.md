## Public Portfolio Version

This repository contains a cleaned and portfolio-oriented version of the original academic project, prepared to be publicly presentable.

Main cleanup and restructuring work included:

- removal of hardcoded API keys;
- removal of personal uploads and private contact details;
- environment-based configuration;
- improved repository structure;
- AI provider abstraction for mock, local model/Ollama and optional OpenAI usage;
- public README, authorship notes and license files.
