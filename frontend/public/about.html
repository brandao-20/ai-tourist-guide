About the project

A cleaner public version of a personalised travel planner.

This repository turns an academic prototype into a safer, simpler and more professional portfolio project.

Project purpose

Personalized Tourist Guide AI helps users plan city visits by combining preferences, destination data, map-based route views and saved itineraries. The current version keeps the architecture understandable and demo-friendly instead of depending on a complex or paid-first AI stack.

What it demonstrates

  • Separated frontend and backend structure.
  • Session-based user accounts with profile and image upload handling.
  • Itinerary search, favourite routes and recent searches.
  • Configuration prepared for public GitHub usage.

Development direction

The project is designed to evolve towards explainable recommendation scoring based on preferences, categories, distance, duration and popularity, while keeping mock/demo mode available for portfolio presentations.
