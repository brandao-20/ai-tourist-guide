How it works

From preferences to a route you can review and save.

The application keeps the planning flow short: choose a destination, describe the trip and inspect the generated itinerary on a map.

1

Choose context

Select a country, city, days available and the type of places you want to visit.

2

Generate itinerary

The backend prepares a structured route response that the frontend can render as a map-first plan.

3

Save useful plans

Authenticated users can keep favourite itineraries and reopen recent searches from the dashboard.

AI and recommendation direction

The public version favours a practical recommendation foundation: mock/demo mode first, explainable ranking next, and optional external or local AI providers only when they add clear value.
